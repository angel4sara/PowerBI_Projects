# Patient Wait List Dashboard

## Project Overview
This Power BI dashboard analyses patient wait list trends including:

- Total wait list size
- Case type distribution (Outpatient / Day Case / Inpatient)
- Time band vs Age profile
- Monthly trends
- Specialty breakdown of waiting patients

## Key Features
- KPI cards for latest and previous wait list values
- Interactive slicers (Archive Date, Case Type, Specialty)
- Trend analysis over time
- Detailed matrix breakdown
- Specialty group comparison

## Tools Used
- Power BI
- DAX
- Data modelling
- Interactive filtering

## Dashboard Pages

### Overview
Summary of key metrics and wait list distribution.

### Detailed View
Detailed matrix showing wait list by age profile and time bands.

### Specialty Breakdown
Bar chart showing wait list distribution across specialties.
